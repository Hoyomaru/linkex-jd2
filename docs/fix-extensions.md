# fix-extensions.ps1

ダウンロードしたファイルの拡張子が無かったり間違っていたりして、画像か動画かわからなくなったときに使うスクリプト。
ファイルの先頭のバイト（マジックナンバー）を読んで本当の種類を判定し、正しい拡張子にリネームする。

## 準備（1回だけ）

1. このリポジトリの `scripts` フォルダ（例: `<このリポジトリ>\scripts`）を、ユーザー環境変数の PATH に入れる
2. PowerShell を開き直す
3. 「スクリプトを実行できません」と出たら、次を1回だけ実行する

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```

## 使い方

調べたいフォルダに移動して実行する。対象は **PowerShell で今いるフォルダ**。

```powershell
cd <調べたいフォルダ>
fix-extensions.ps1            # 確認だけ（リネームしない）
fix-extensions.ps1 -Apply     # 実際にリネームする
```

| オプション | 意味 |
|---|---|
| （なし） | 何をリネームするか表示するだけ。ファイルは変わらない |
| `-Apply` | 実際にリネームする |
| `-Recurse` | サブフォルダの中も対象にする |
| `-Path <フォルダ>` | 今いるフォルダ以外を対象にする |

## 判定できる種類

| 分類 | 拡張子 |
|---|---|
| 画像 | jpg / png / gif / webp / bmp / avif / heic |
| 動画 | mp4 / mov / webm / mkv / avi / flv / ts |
| 音声 | mp3 / m4a / wav |
| その他 | pdf / zip |

## リネームのルール

- **拡張子が無い** → 付け足す（`abc` → `abc.mp4`）
- **拡張子が間違っている** → 差し替える（中身が PNG の `pic.mp4` → `pic.png`）
- **見慣れない拡張子** → 消さずに付け足す（`video.2024` → `video.2024.mp4`）
- **拡張子が正しい** → 何もしない（`.jpeg` と `.jpg`、`.m4v` と `.mp4` などは同じ扱い）
- **同じ名前のファイルがある** → `名前 (1).jpg` のように番号を付ける。上書きはしない
- **判定できない** → 何もしない。拡張子が無いものだけ「判定できず」として表示する。中身がエラーページ（HTML）だったり、途中で切れていたりすることが多い

## 出力の例

```
予定: clip -> clip.mp4
予定: pic.mp4 -> pic.png
? 判定できず: mystery

リネーム予定: 2 件 / 拡張子が正しい: 10 件 / 判定できず: 1 件
確認だけしました。実際にリネームするには -Apply を付けて実行してください。
```

PowerShell 7（pwsh）と Windows PowerShell 5.1 の両方で動く。
