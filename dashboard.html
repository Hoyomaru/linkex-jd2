    JDownloader 2

    JD2の「設定 → 詳細設定」で「RemoteAPI: Deprecated Api Enabled」をオンにして、JD2を再起動しておきます。保存先にもう同じ名前のファイルがあると、JD2が上書きするか聞いてきて止まるので、JD2の「ファイルが既に存在する場合」の設定も確かめておいてください。

    保存先

    この下に「共有名\共有内のフォルダ\ファイル」の形で保存されます。共有の中身がフォルダ1つだけなら、共有名の段を飛ばして「そのフォルダ\…」から保存します（キューに追加した後の件は変わりません）。

    動作

    Linkex

    署名のために、固定タブでLinkexのドライブを開いています。ログインが切れたときは、このタブでログインし直してください。

    アカウント

    切り替えに使う転送量期限

    アカウントの足し方：Linkex で右上のアイコン →「ログアウト」→ 別のアカウントでログインすると、ここに足されます。拡張機能が使う Linkex（このブラウザ）で行ってください。期限は Linkex が最後にログイン情報を更新してから20日です。

    ダウンロード済みの記録

    同じ中身のファイルを「重複のため省略」にするための記録です。消すと、以前ダウンロードしたファイルも次からはもう一度ダウンロードします。キュー・設定・処理ログは残ります。
